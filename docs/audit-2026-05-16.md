# AUDYT bodysync — raport zbiorczy (2026-05-16)

Trzy audyty równoległe: **security**, **frontend-designer** (UX/UI mobile+desktop), **auditor** (funkcjonalność + dług techniczny + gaps).

**TL;DR:** zero krytyków P0 w security — fundamenty AWS solidne. W UX są P0 widoczne dla każdego usera, najgrubszy to **fonty w ogóle się nie ładują** (JetBrains Mono + Inter referowane w 30+ miejscach, brak `@font-face`/preload — wszystko leci na system fallback).

## 🔥 Action plan — kolejność

### Sprint #1 (ten tydzień) — visible polish + security hardening

**Frontend P0 (visible regression na każdym ekranie):**

1. **Załadować JetBrains Mono + Inter** (`apps/web/index.html` + `apps/web/public/fonts/*.woff2` + `apps/web/src/index.css` `@font-face`). 30 min, +30KB gzip, podnosi cały premium feel. CSP `font-src 'self'` wymaga self-host (`apps/web/public/_headers:7`).
2. **`100vh` → `100dvh`** w `apps/web/src/index.css:1859` (chat-screen na iOS Safari urywa się pod bottom nav).
3. **Chart tooltipy: `onTouchStart`** w `apps/web/src/components/dashboard/MetricChart.tsx:163` i `WeightChart.tsx:241` (na mobile pierwszego tap'a hover nie pokazuje).
4. **Sidebar `position: fixed`** zamiast `sticky` (`apps/web/src/index.css:107-117`) — sticky w grid item psuje się na długim Dashboardzie.
5. **Body scroll lock + `aria-modal="true"`** w `RecipeModal.tsx` + `DemoGallery.tsx` — background scrolluje pod modalem na mobile, brak `role="dialog"` aria-modal w RecipeModal.
6. **Lazy-load `ChatScreen` + dynamic `import('./recipes.json')`** — recipes.json 314KB w main bundle to ~70% obecnego JS (152KB gzip). `React.lazy(ChatScreen)` w `Dashboard.tsx`. -70% bundle dla userów nie wchodzących w chat.

**Security P1:**

7. **Nonce w Google Sign-In** (`apps/web/src/components/LoginScreen.tsx:60-72` + `apps/api/handlers/google_auth/service.py:39-52`) — zamyka replay window dla wykradzionego id_token (token żyje ~1h, dziś brak nonce check). Frontend `crypto.randomUUID()` w `sessionStorage`, backend sprawdza `idinfo["nonce"] == req.nonce` + atomic single-use `NONCE#{value}` z TTL 5min w DDB (analog `STRAVA_OAUTH_STATE#`).
8. **Strava OAuth callback wymaga JWT cookie** (`apps/api/handlers/strava_oauth_callback/handler.py:69-79`) — sprawdza że `state.user_id == jwt.user_id`. Defense-in-depth przed wykradnięciem state nonce z browser history.
9. **PowerUserAccess: explicit `Deny` na drogie AI services** (`infrastructure/terraform/bootstrap/oidc.tf:46`) — `Deny bedrock/sagemaker/comprehend/rekognition/transcribe/polly/lex/kendra`. Kradzież OIDC nie zrobi $10k Bedrock bill. ~10 LOC HCL.
10. **Cookie `SameSite=Lax` → `Strict`** (`apps/api/handlers/google_auth/handler.py:62` + `auth_logout/handler.py:35`) — eliminuje cały GET-CSRF surface. Obecny gadget: `GET /api/strava/oauth/start` zwraca 302 do Stravy authorize z poprawnym state, kliknięcie linku z malicious site może wymusić ofiarę.

**Operational P1:**

11. **Frontend CI workflow** (`.github/workflows/web.yml`) — `cd apps/web && npm ci && npm run typecheck && npm run test` na PR. Frontend deployuje się auto z main przez Cloudflare bez żadnego gating; broken build leci do prod.
12. **`apps/api/shared/http.py`** z `extract_session_cookie(event)` + `response(status, body)` — usuwa ~300 LOC duplikacji w 9 handlerach (`activities_list`, `activity_suggestion`, `plan`, `profile_targets`, `strava_oauth_start`, `advisor_chat`, `tdee_recalc`, `measurements`, `api_read`).

**Razem**: ~6-8h, każdy krok jako osobny PR per memory PR workflow.

## 🔐 Security — szczegóły

### Wysokie (P1)

- **P1-1 Brak `nonce` w Google Sign-In** = replay window. `LoginScreen.tsx:60-72` + `google_auth/service.py:39-52`.
- **P1-2 Strava OAuth callback bez JWT validation** — state row trzyma `user_id`, ale callback nie sprawdza że to ten sam user co JWT. `strava_oauth_callback/handler.py:69-79`.
- **P1-3 GHA OIDC role ma `PowerUserAccess`** — `bedrock:*`/`sagemaker:*`/etc. dostępne. `bootstrap/oidc.tf:46`.
- **P1-4 CORS `allow_credentials=true` + cookie `SameSite=Lax`** = GET-CSRF window na `GET /api/me`, `GET /api/strava/oauth/start`, etc.
- **P1-5 Brak audit logu dla SK access** — handlery logują `user_id`, nie SK; przy security incident brak forensics path.

### Średnie (P2)

- P2-1 CSP `'unsafe-inline'` w `style-src` (Vite quirk, TODO nonce-based gdy dashboard scaffold) — `_headers:6`.
- P2-2 CSP `img-src 'self' data: https:` — overly permissive (dowolny https host).
- P2-4 **Brak WAF** na API GW — rate-limit per-IP brak, geo block brak, IP reputation brak.
- P2-6 JWT TTL 30 dni bez refresh / per-session revocation — wykradzione cookie żyje miesiąc.
- P2-9 Strava `verify_token` bez `min_length` guard — `strava_webhook/handler.py:84-91`.
- P2-10 `logger.exception` w `google_auth/handler.py:111` może lognąć id_token w traceback.

### Pozytywy (sprawdzone, OK)

1. **PK isolation pełne** — każdy IAM ma `LeadingKeys=USER#*` (lub `EVENT#strava`, `STRAVA_OAUTH_STATE#*`, `WAITLIST`, `RECIPES`).
2. **Sekrety zero w git** — `git log -p -S 'sk-ant-' -S 'GOCSPX-' -S 'AKIA' -S 'BEGIN PRIVATE KEY'` zero hitów.
3. **GHA actions pinned na full SHA-1** z Dependabot auto-bump.
4. **OIDC trust policy** zwężona do `repo:tlyko/bodysync:ref:refs/heads/main` + `:pull_request`.
5. **`iam:PassRole`** z `iam:PassedToService = lambda.amazonaws.com` condition.
6. **Webhook idempotency + constant-time `hmac.compare_digest`** w obu (HAE + Strava).
7. **Strava OAuth state — atomic single-use** z `delete_item_if_exists` + `attribute_exists` condition.
8. **JWT minimal payload** (tylko user_id+iat+exp), min 32-byte secret enforced.
9. **Per-user HAE webhook secret** (tomek + weronika osobne SSM).
10. **Prompt injection guards** w `ChatRequest` schema + system_prompt + zero content logging w LLM paths.
11. **S3** block_public_access + AES256 + versioning + DenyNonTLS + lifecycle → Glacier.
12. **DDB** encryption at rest + PITR + Stream NEW_IMAGE z `filter_criteria PK=EVENT#strava` (cost defense).
13. **API GW throttling per-route** (50 req/s default, 5 req/s advisor_chat).
14. **CSP restrykcyjne** + HSTS + Referrer-Policy + Permissions-Policy + frame-ancestors:'none'.
15. **localStorage/sessionStorage nie używane dla auth** (zero hits, JWT tylko HttpOnly cookie).
16. **Cost-guard alarm Anthropic** + SNS → Telegram, smoke-tested.

## 🎨 UX/UI — szczegóły

### Mobile P0

- **Fonty nie ładują się** (`apps/web/index.html`, `index.css`) — JetBrains Mono + Inter referowane w 30+ miejscach, brak `@font-face`/preload/Google Fonts. Wszystko leci na `ui-monospace` (Menlo). **Single biggest visual polish win.**
- **`100vh` w chat-screen** na iOS Safari (`index.css:1859`) — magic number -220px nie pasuje do mobile, chat overflowuje pod bottom nav lub jest za niski. Fix: `100dvh`.
- **Touch targets w 7-item bottom nav za małe** — `390/7 ≈ 55px` szerokość, padding `0.4rem 0.25rem`, faktyczna tap target wysokość poniżej 44px Apple HIG. Labele "Plan Treningowy" / "Asystent AI" ucinają się.
- **Chart tooltipy nie działają na touch** (`MetricChart.tsx:163`, `WeightChart.tsx:241`) — `onMouseEnter` only, iOS Safari wymaga drugiego tap.

### Desktop P0

- **Sidebar `position: sticky` w grid item** (`index.css:114-117`) — znany W3C quirk, sticky nie działa w grid; przy długim scrollu sidebar zjeżdża. Fix: `position: fixed`.
- **`.app-content max-width: 1240px`** (`index.css:201`) — na 4K monitor 2400px pustki po bokach.
- **Gradient text H1 bez fallbacku** (`-webkit-text-fill-color: transparent`) — Firefox <49 / Safari <14 = invisible text.

### Spójność z `docs/health-dashboard-prototype.jsx`

- **Gap 1**: StatCard brak decorative ring/circle (prototype linia 207-216).
- **Gap 2**: brak DataSourceBadge na Dashboard (prototype linia 247-278) — user nie wie czy HAE webhook żyje.
- **Gap 3-7**: WeightChart line vs bars, NutritionDonut inny color mapping, RecipeCard zminimalizowany, brak globalnego SyncButton, typography weights matchują (gdyby fonty się ładowały).

### A11y P0

- Kontrast `--text-dim` (#5a6f8e) na `--bg` = 4.04:1, **fail WCAG AA** (wymaga 4.5:1).
- ChatInput textarea bez `<label>` — sam placeholder znika dla screen reader.
- Modale (RecipeModal, DemoGallery) bez focus-trap; Tab wychodzi do background.
- `RecipeModal` ma `role="dialog"` ale brak `aria-modal="true"` + `aria-labelledby`.
- Color-only signals w kcal-balance status (cyan/green/red bez tekstu na chart bars).

### Performance P0

- **`recipes.json` 314KB synchronous import** (`recipes.ts:9`) → main bundle 152KB gzip (~70% to recipes).
- **Brak code-splitting w ogóle** — Dashboard.tsx ładuje 16 sub-komponentów synchronously; TDEECalculatorWizard (414 LOC) + PlanScreen + ChatScreen wszystko na initial paint.
- **Brak `loading="lazy"`** na `DemoGallery` PNG-i (175 KB / 227 KB / 100 KB / 78 KB).

### Brakujące komponenty UX

- Toast/notification system (każdy formularz reinventuje `setTimeout 3000ms`).
- Skeleton screens (wszędzie `<p>Wczytywanie…</p>`).
